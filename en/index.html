Foruster

Written in Rust, for Linux and Windows.

Forensic acquisition of running computers. It copies memory and disks without touching the machine and leaves a case file that someone else can check.

Project website (in Spanish)

Screenshots use sample data.

  1. Home

    Explore the computer without touching it, or acquire evidence.

  2. Copy

    The copy runs with its hash, computed while it copies, not afterwards.

  3. Check

    When it finishes, the case file is checked. Anything that could not be read is logged with the reason.

  4. Seal

    The case file’s timestamp and signatures.

  • Opens disks read-only and installs nothing.
  • Hashes each item while it copies it.
  • The case file can be checked with free tools.
  • In development, with in-house testing only. Not in service.
